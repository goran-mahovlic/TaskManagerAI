# Alati domene vjestine

Kanonski alati domene vjestine. Prije pisanja nove skripte pokreni `katalog trazi <svrha>`; ako alat postoji, nadogradi ga.
- `ActivityParser.ts` (cli, vlasnik jelena): ActivityParser - Parse session activity for PAI repo update documentation. Poziv: `bun run ~/.claude/skills/CORE/Tools/ActivityParser.ts --today`.
- `AddBg.ts` (cli, vlasnik jelena): add-bg - Add Background Color CLI. Poziv: `bun ~/.claude/skills/CORE/Tools/AddBg.ts`.
- `Banner.ts` (cli, vlasnik jelena): PAI Banner - Dynamic Multi-Design Neofetch Banner. Poziv: `bun ~/.claude/skills/CORE/Tools/Banner.ts`.
- `FeatureRegistry.ts` (cli, vlasnik jelena): Feature Registry CLI. Poziv: `bun run ~/.claude/skills/CORE/Tools/FeatureRegistry.ts <command> [options]`.
- `GenerateSkillIndex.ts` (cli, vlasnik jelena): GenerateSkillIndex.ts. Poziv: `bun run ~/.claude/skills/CORE/Tools/GenerateSkillIndex.ts`.
- `LearningPatternSynthesis.ts` (cli, vlasnik jelena): LearningPatternSynthesis - Aggregate ratings into actionable patterns. Poziv: `bun run ~/.claude/skills/CORE/Tools/LearningPatternSynthesis.ts --week`.
- `pai.ts` (cli, vlasnik jelena): pai - Personal AI CLI Tool. Poziv: `bun ~/.claude/skills/CORE/Tools/pai.ts`.
- `RemoveBg.ts` (cli, vlasnik jelena): remove-bg - Background Removal CLI. Poziv: `bun ~/.claude/skills/CORE/Tools/RemoveBg.ts`.
- `SessionProgress.ts` (cli, vlasnik jelena): Session Progress CLI. Poziv: `bun run ~/.claude/skills/CORE/Tools/SessionProgress.ts <command> [options]`.
- `SkillSearch.ts` (cli, vlasnik jelena): SkillSearch.ts. Poziv: `bun run ~/.claude/skills/CORE/Tools/SkillSearch.ts <query>`.
- `update-patterns.sh` (cli, vlasnik jelena): Update Fabric patterns from upstream. Poziv: `bash ~/.claude/skills/CORE/Tools/fabric/update-patterns.sh`.
