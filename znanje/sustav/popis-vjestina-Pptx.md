# Vještina Pptx

Vještina Pptx: PowerPoint presentation creation, editing, and analysis toolkit. Create presentations from scratch using HTML-to-PPTX workflow, edit existing presentations using OOXML manipulation, work with templates, and generate thumbnail grids.
Koristi se kad: PowerPoint, pptx file, create slides, presentation, slide deck.
Status u katalogu alata je eksperiment, vlasnik regoc.
Nije dodijeljena nijednom agentu u registru.
Poziva se alatom Skill (`Pptx`) ili čitanjem `~/.claude/skills/Pptx/SKILL.md`.
Vještina nema vlastitih tijekova (mapa Workflows ne postoji ili je prazna).
