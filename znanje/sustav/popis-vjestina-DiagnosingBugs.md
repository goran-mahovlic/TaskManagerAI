# Vještina DiagnosingBugs

Vještina DiagnosingBugs: Disciplined 6-phase debug loop -- REPRODUCE, ISOLATE, HYPOTHESIZE, VERIFY, FIX, REGRESS.
Koristi se kad: debugging, bug diagnosis, investigate issue, why does X fail, troubleshoot, fix bug, root cause analysis.
Status u katalogu alata je kanonski, vlasnik jelena.
Dodijeljena je agentima: Jelena.
Poziva se alatom Skill (`DiagnosingBugs`) ili čitanjem `~/.claude/skills/DiagnosingBugs/SKILL.md`.
Vještina nema vlastitih tijekova (mapa Workflows ne postoji ili je prazna).
