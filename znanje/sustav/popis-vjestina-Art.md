# Vještina Art

Vještina Art: Complete visual content system.
Koristi se kad: user wants to create visual content, illustrations, diagrams, OR mentions art, header images, visualizations, mermaid, flowchart, technical diagram, infographic, PAI icon, pack icon, or PAI pack icon.
Status u katalogu alata je kanonski, vlasnik gita.
Dodijeljena je agentima: Gita.
Poziva se alatom Skill (`Art`) ili čitanjem `~/.claude/skills/Art/SKILL.md`.

## Tijekovi vještine
Vještina ima 8 tijekova u mapi Workflows.
- `ArtisticFlowchart.md`: Hand-drawn flowcharts using Mermaid.js with multi-agent collaboration for structure and styling.
- `CreatePAIPackIcon.md`: Generate 256x256 transparent PNG icons for PAI packs.
- `Essay.md`: Charcoal Architectural Sketch TECHNIQUE — Applied to CONTENT-RELEVANT subjects.
- `Frameworks.md`: Hand-drawn frameworks, mental models, and conceptual diagrams using UL aesthetic.
- `Mermaid.md`: Hand-drawn technical diagrams combining Mermaid structure with Excalidraw sketchy aesthetic and UL color scheme.
- `Stats.md`: Single striking statistics illustrated as visual data points using UL aesthetic.
- `TechnicalDiagrams.md`: Clean Excalidraw-style technical diagrams with custom typography aesthetic.
- `Visualize.md`: Intelligent multi-modal visualization combining optimal approaches based on content analysis.
