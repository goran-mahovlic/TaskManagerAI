# Alati domene git

Kanonski alati domene git. Prije pisanja nove skripte pokreni `katalog trazi <svrha>`; ako alat postoji, nadogradi ga.
- `gitlab_api_audit.sh` (cli, vlasnik jelena): GitLab revizija preko API-ja (bez kloniranja) — /. Poziv: `bash ${SUSTAV_DIR}/tools/git/gitlab_api_audit.sh`. Stare putanje: `${SUSTAV_DIR}/tools/gitlab_api_audit.sh`.
