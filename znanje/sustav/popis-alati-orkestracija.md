# Alati domene orkestracija

Kanonski alati domene orkestracija. Prije pisanja nove skripte pokreni `katalog trazi <svrha>`; ako alat postoji, nadogradi ga.
- `adversarial-pozivac.ts` (modul, vlasnik jelena): adversarial-pozivac — TKO odgovara na pitanje leće (W5 /). Poziv: `import iz ${SUSTAV_DIR}/tools/orkestracija/adversarial-pozivac.ts`. Stare putanje: `${SUSTAV_DIR}/tools/adversarial-pozivac.ts`.
- `adversarial-provjeri.ts` (cli, vlasnik jelena): adversarial-provjeri — pokreni adversarijalnu provjeru nalaza jednog koraka (W5 /). Poziv: `bun ${SUSTAV_DIR}/tools/orkestracija/adversarial-provjeri.ts [ …]`. Stare putanje: `${SUSTAV_DIR}/tools/adversarial-provjeri.ts`.
- `agent-mq.ts` (cli, vlasnik jelena): Agent Message Queue CLI. Poziv: `bun ${SUSTAV_DIR}/tools/orkestracija/agent-mq.ts check --agent jelena`. Stare putanje: `${SUSTAV_DIR}/tools/agent-mq.ts`.
- `BugFixWorkflow.ts` (cli, vlasnik jelena): REGOČ BugFix Workflow. Poziv: `bun ${SUSTAV_DIR}/workflows/BugFixWorkflow.ts`.
- `CreateProjectWorkflow.ts` (cli, vlasnik jelena): REGOČ Create Project Workflow. Poziv: `bun ${SUSTAV_DIR}/workflows/CreateProjectWorkflow.ts`.
- `lanac-otvori.ts` (cli, vlasnik jelena): lanac-otvori.ts — otvori zadatak po PREDLOŠKU i zadatak DOJAVE (U4 /). Poziv: `bun ${SUSTAV_DIR}/tools/orkestracija/lanac-otvori.ts`. Stare putanje: `${SUSTAV_DIR}/tools/lanac-otvori.ts`.
- `lanac-puni.ts` (cli, vlasnik jelena): lanac-puni.ts — PUNI LANAC za težinu ≥ prag B (U5 /). Poziv: `bun ${SUSTAV_DIR}/tools/orkestracija/lanac-puni.ts [--planer ollama|claude] [--model M]`. Stare putanje: `${SUSTAV_DIR}/tools/lanac-puni.ts`.
