# Vještina Browser

Vještina Browser: Debug-first browser automation with always-on visibility. Console logs, network requests, and errors captured by default.
Koristi se kad: browser, screenshot, debug web, verify UI, troubleshoot frontend.
Status u katalogu alata je kanonski, vlasnik grga.
Dodijeljena je agentima: Grga.
Poziva se alatom Skill (`Browser`) ili čitanjem `~/.claude/skills/Browser/SKILL.md`.

## Tijekovi vještine
Vještina ima 5 tijekova u mapi Workflows.
- `Extract.md`: Extract content from web pages.
- `Interact.md`: Fill forms, click buttons, and interact with page elements.
- `Screenshot.md`: Take a screenshot of a URL.
- `Update.md`: Sync Browser FileMCP with official Playwright MCP capabilities.
- `VerifyPage.md`: Verify a page loads correctly and check for errors.
