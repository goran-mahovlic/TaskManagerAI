# Vještina Pdf

Vještina Pdf: Comprehensive PDF manipulation toolkit for extracting text and tables, creating new PDFs, merging/splitting documents, and handling forms.
Koristi se kad: user needs to fill in a PDF form, programmatically process, generate, or analyze PDF documents, extract tables from PDFs, merge or split PDF files, add watermarks, or perform OCR on scanned documents.
Status u katalogu alata je eksperiment, vlasnik regoc.
Nije dodijeljena nijednom agentu u registru.
Poziva se alatom Skill (`Pdf`) ili čitanjem `~/.claude/skills/Pdf/SKILL.md`.
Vještina nema vlastitih tijekova (mapa Workflows ne postoji ili je prazna).
