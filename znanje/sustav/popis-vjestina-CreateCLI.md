# Vještina CreateCLI

Vještina CreateCLI: Generate TypeScript CLIs.
Koristi se kad: create CLI, build CLI, command-line tool. SkillSearch('createcli') for docs.
Status u katalogu alata je kanonski, vlasnik jelena.
Dodijeljena je agentima: Jelena.
Poziva se alatom Skill (`CreateCLI`) ili čitanjem `~/.claude/skills/CreateCLI/SKILL.md`.

## Tijekovi vještine
Vještina ima 3 tijekova u mapi Workflows.
- `AddCommand.md`: Extend existing CLI with new commands while maintaining code quality and consistency.
- `CreateCli.md`: Generate production-quality TypeScript command-line interfaces following llcli pattern and CLI-First Architecture.
- `UpgradeTier.md`: Migrate from manual parsing to Commander.js when CLI grows complex.
