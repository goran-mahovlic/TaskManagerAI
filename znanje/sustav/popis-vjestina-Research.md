# Vještina Research

Vještina Research: Comprehensive research, analysis, and content extraction system.
Koristi se kad: user says 'do research', 'do extensive research', 'quick research', 'minor research', 'research this', 'find information', 'investigate', 'extract wisdom', 'extract alpha', 'analyze content', 'can't get this content', 'use fabric', OR requests any web/content research. Supports three research modes (quick/standard/extensive), deep content analysis, intelligent retrieval, and 242+ Fabric patterns. NOTE: For due diligence, OSINT, or background checks, use OSINT skill instead.
Status u katalogu alata je eksperiment, vlasnik regoc.
Nije dodijeljena nijednom agentu u registru.
Poziva se alatom Skill (`Research`) ili čitanjem `~/.claude/skills/Research/SKILL.md`.

## Tijekovi vještine
Vještina ima 13 tijekova u mapi Workflows.
- `AnalyzeAiTrends.md`: Perform deep trend analysis across historical AI news logs to identify patterns, paradigm shifts, and future predictions.
- `ClaudeResearch.md`: Intelligent multi-query WebSearch using Claude's built-in tool.
- `Enhance.md`: Comprehensive content enhancement for blog posts and articles.
- `ExtensiveResearch.md`: Mode: 3 researcher types x multiple threads each | Timeout: 5 minutes.
- `ExtractAlpha.md`: Extract the highest-alpha ideas from content using deep thinking analysis.
- `ExtractKnowledge.md`: Intelligently extracts knowledge and signal points from any input source (URLs, YouTube videos, PDFs, presentations, research papers, etc.).
- `Fabric.md`: Intelligent pattern selection for Fabric CLI.
- `InterviewResearch.md`: Preparing research for sponsored interviews at information security or tech startups.
- `QuickResearch.md`: Mode: Single Claude researcher, 1 query | Timeout: 30 seconds.
- `Retrieve.md`: Intelligent multi-layer content retrieval system for DIFFICULT content retrieval.
- `StandardResearch.md`: Mode: 2 different researcher types, 1 query each | Timeout: 1 minute.
- `WebScraping.md`: Web scraping and crawling using WebFetch for simple pages, BrightData MCP for CAPTCHA/blocking, and Apify MCP for social media.
- `YoutubeExtraction.md`: Extract content from YouTube videos using Fabric CLI.
