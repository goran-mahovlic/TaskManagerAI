# Vještina TDD

Vještina TDD: Vertical-slice TDD workflow -- test FIRST, then implement. Red-Green-Refactor cycle.
Koristi se kad: TDD, test driven, test first, write tests, red green refactor, vertical slice, behavior test.
Status u katalogu alata je kanonski, vlasnik jelena.
Dodijeljena je agentima: Jelena.
Poziva se alatom Skill (`TDD`) ili čitanjem `~/.claude/skills/TDD/SKILL.md`.
Vještina nema vlastitih tijekova (mapa Workflows ne postoji ili je prazna).
