# Vještina McpBuilder

Vještina McpBuilder: Guide for creating high-quality MCP (Model Context Protocol) servers that enable LLMs to interact with external services through well-designed tools.
Koristi se kad: build MCP server, create MCP, FastMCP, model context protocol, MCP tools.
Status u katalogu alata je zastario, vlasnik regoc.
Nije dodijeljena nijednom agentu u registru.
Poziva se alatom Skill (`McpBuilder`) ili čitanjem `~/.claude/skills/McpBuilder/SKILL.md`.
Vještina nema vlastitih tijekova (mapa Workflows ne postoji ili je prazna).
