# Alati domene rag

Kanonski alati domene rag. Prije pisanja nove skripte pokreni `katalog trazi <svrha>`; ako alat postoji, nadogradi ga.
<!-- uvjet-redak: rag --> - `chroma-adapter.ts` (cli, vlasnik jelena): ChromaDB Adapter. Poziv: `bun ${SUSTAV_DIR}/tools/rag/lib/adapters/chroma-adapter.ts`.
- `dual-adapter.ts` (cli, vlasnik jelena): Dual Backend Adapter. Poziv: `bun ${SUSTAV_DIR}/tools/rag/lib/adapters/dual-adapter.ts`.
- `HindsightConfig.ts` (modul, vlasnik jelena): Čiste funkcije za Hindsight: postavka hindsight.max_concurrent (settings/settings_history), mapiranje model-config spec → Hindsight provider, okolina s otiskom (bez tajni), vrata kvote, odluka restarta. Poziv: `import { … } from '${SUSTAV_DIR}/tools/hindsight/HindsightConfig'`.
- `petlja.sh` (cli, vlasnik jelena): Stalna petlja (30 s, flock singleton) koja zove hindsight_uskladi.ts jednom; diže Hindsight nakon restarta kontejnera; pokreće je kuka EnsureRegocDaemon. Poziv: `bash ${SUSTAV_DIR}/tools/hindsight/petlja.sh start|stop|status`.
- `hindsight_uskladi.ts` (cli, vlasnik jelena): Drži Hindsight (17792) živim i usklađenim: model iz model-config.json componentOverrides.hindsight[_retain|_reflect] (anthropic→claude-code, ollama, openrouter) i usporedni pozivi iz regoc.db settings hindsight.max_concurrent; restart samo kad nema retaina; vrata kvote; promjena modela. Poziv: `bun ${SUSTAV_DIR}/tools/hindsight/hindsight_uskladi.ts stanje | jednom | vrata | model <hindsight|hindsight_retain|hindsight_reflect> <spec|zadano>`.
