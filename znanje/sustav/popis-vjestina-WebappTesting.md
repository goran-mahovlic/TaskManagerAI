# Vještina WebappTesting

Vještina WebappTesting: Playwright-based toolkit for testing and automating local web applications.
Koristi se kad: test webapp, browser automation, Playwright script, verify UI, debug frontend, capture screenshot, browser logs, web testing, automation script, inspect DOM.
Status u katalogu alata je eksperiment, vlasnik regoc.
Nije dodijeljena nijednom agentu u registru.
Poziva se alatom Skill (`WebappTesting`) ili čitanjem `~/.claude/skills/WebappTesting/SKILL.md`.
Vještina nema vlastitih tijekova (mapa Workflows ne postoji ili je prazna).
