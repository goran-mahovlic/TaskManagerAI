# Vještina Backup

Vještina Backup: Full PAI system backup. Creates timestamped zip of ~/.claude/ and current folder.
Koristi se kad: /backup, backup system, create backup, save state.
Status u katalogu alata je zastario, vlasnik regoc.
Nije dodijeljena nijednom agentu u registru.
Poziva se alatom Skill (`Backup`) ili čitanjem `~/.claude/skills/Backup/SKILL.md`.
Vještina nema vlastitih tijekova (mapa Workflows ne postoji ili je prazna).
