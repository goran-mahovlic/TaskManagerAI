# Vještina Docx

Vještina Docx: Comprehensive Word document creation, editing, and analysis with support for tracked changes, comments, formatting preservation, and text extraction using OOXML manipulation and docx-js library.
Koristi se kad: Word document, docx file, create Word, edit Word, OOXML document.
Status u katalogu alata je eksperiment, vlasnik regoc.
Nije dodijeljena nijednom agentu u registru.
Poziva se alatom Skill (`Docx`) ili čitanjem `~/.claude/skills/Docx/SKILL.md`.
Vještina nema vlastitih tijekova (mapa Workflows ne postoji ili je prazna).
