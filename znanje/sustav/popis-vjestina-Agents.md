# Vještina Agents

Vještina Agents: Dynamic agent composition and management system.
Koristi se kad: user says create custom agents, spin up custom agents, specialized agents, OR asks for agent personalities, available traits, agent voices. Handles custom agent creation, personality assignment, voice mapping, and parallel agent orchestration.
Status u katalogu alata je zastario, vlasnik regoc.
Dodijeljena je agentima: REGOČ.
Poziva se alatom Skill (`Agents`) ili čitanjem `~/.claude/skills/Agents/SKILL.md`.

## Tijekovi vještine
Vještina ima 3 tijekova u mapi Workflows.
- `CreateCustomAgent.md`: Creates custom agents with unique personalities and voice IDs using AgentFactory.
- `ListTraits.md`: Shows all available traits that can be composed into custom agents.
- `SpawnParallelAgents.md`: Launches multiple generic Intern agents for parallel grunt work (NOT custom agents).
