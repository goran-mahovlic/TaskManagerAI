# Vještina Recon

Vještina Recon: Security reconnaissance.
Koristi se kad: recon, reconnaissance, bug bounty, attack surface. SkillSearch('recon') for docs.
Status u katalogu alata je kanonski, vlasnik malik.
Dodijeljena je agentima: Malik.
Poziva se alatom Skill (`Recon`) ili čitanjem `~/.claude/skills/Recon/SKILL.md`.

## Tijekovi vještine
Vještina ima 5 tijekova u mapi Workflows.
- `BountyPrograms.md`: Discover and monitor public bug bounty programs from aggregated sources.
- `DomainRecon.md`: Comprehensive domain infrastructure mapping and enumeration.
- `IpRecon.md`: Comprehensive investigation of individual IP addresses.
- `NetblockRecon.md`: CIDR range and IP block investigation.
- `PassiveRecon.md`: Safe, non-intrusive intelligence gathering using only public sources.
