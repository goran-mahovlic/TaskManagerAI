# Vještina Excalidraw

Vještina Excalidraw: Generate hand-drawn diagrams using Excalidraw format. Converts .excalidraw JSON to SVG and PNG.
Koristi se kad: excalidraw diagram, hand-drawn diagram, whiteboard sketch, convert excalidraw to svg, convert excalidraw to png.
Status u katalogu alata je kanonski, vlasnik gita.
Dodijeljena je agentima: Gita i Grga.
Poziva se alatom Skill (`Excalidraw`) ili čitanjem `~/.claude/skills/Excalidraw/SKILL.md`.

## Tijekovi vještine
Vještina ima 1 tijekova u mapi Workflows.
- `TextChange.md`: Trigger: Korisnik traži promjenu teksta u Excalidraw dijagramu.
